                                    Change Detection Filters
                                    
Configure what activity should NOT trigger CHANGED status.
                                        Use this to filter out automated notifications or non-blocking feedback.


                                    

                                        
                                        

                                        

                                    

                                    

                                        💬 Comments are general discussion messages in the PR
                                        conversation
                                        (e.g., bot notifications, questions, updates). Use this to filter informational
                                        messages that don't require action.
                                    


                                    

                                        
                                        

                                        

                                    

                                    

                                        ✅ Reviews are formal code review submissions with
                                        approval/change
                                        request states (created via "Review changes" button). Use this to ignore
                                        optional
                                        reviewers whose approval isn't required.
                                    


                                    
                                    

                                        🔀 Built-in pattern:
                                        ^(Merge (branch|remote-tracking branch).*(main|origin/main)|Merge main
                                            into )

                                        Uncheck to use only your custom patterns below, or to define your own merge
                                        filter.
                                    


                                    
                                    
                                    
                                    

                                        📝 Filter commits by message patterns (e.g., ^docs: ignores
                                        documentation commits, ^test: ignores test-only commits).
                                    


                                    

                                        Note: Approved reviews are always ignored (built-in behavior).
